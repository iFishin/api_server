# 云端留言板使用指南

一个创意十足的云状留言板，带有浮动云朵效果、点赞、回复功能和1分钟速率限制。

## 🎨 页面特色

### 视觉设计
- **天空背景**：渐变色天空效果（蓝天到金黄色）
- **星星点缀**：闪烁的星星动画
- **云状留言**：每条留言呈现为可爱的云朵形状
- **浮动动画**：云朵随机位置，自动上下左右浮动
- **三种尺寸**：小、中、大云朵随机分布

### 交互功能
- **留言发布**：用户名必填，邮箱和内容选填（内容最多500字）
- **速率限制**：1分钟内只能提交一次，带倒计时提示
- **点赞系统**：可以给留言点赞/取消点赞，数据持久化
- **回复功能**：支持回复留言，形成讨论串
- **置顶显示**：置顶留言带有特殊脉冲动画
- **统计信息**：显示总留言数、点赞数、已显示留言数
- **加载更多**：分页加载，每次20条
- **回到顶部**：快速返回页面顶部

## 🚀 访问方式

### 方式一：从主页进入
1. 启动服务器：`npm run dev`
2. 访问主页：`http://localhost:5173/`
3. 点击"☁️ 云端留言板"按钮

### 方式二：直接访问
直接访问：`http://localhost:5173/message-board`

## 📝 使用说明

### 1. 发布留言

在页面底部的留言框中：
1. **输入昵称**（必填）：例如 "张三"
2. **输入邮箱**（选填）：例如 "zhangsan@example.com"
3. **输入内容**（必填，最多500字）：写下你的想法
4. 点击"发送到云端"按钮

**注意**：
- 发送成功后，需要等待 60 秒才能再次发送
- 剩余等待时间会在按钮上方显示

### 2. 浏览留言

- **云朵展示**：留言以云朵形式在天空中浮动
- **鼠标悬停**：悬停在云朵上会放大显示
- **点击云朵**：查看留言详情（当前版本在控制台打印）

### 3. 点赞留言

1. 找到喜欢的留言云朵
2. 点击 ❤️ 按钮
3. 点赞后按钮变红色
4. 再次点击可取消点赞
5. 点赞记录保存在本地（刷新页面不会丢失）

### 4. 回复留言

1. 点击留言云朵上的"回复"按钮
2. 页面自动滚动到底部留言框
3. 留言框标题显示"回复 @用户名"
4. 输入回复内容后提交
5. 回复会显示在原留言下方

### 5. 查看回复

- 如果留言有回复，会显示在留言内容下方
- 回复数量显示在"回复"按钮旁边：`回复 (3)`
- 回复以小卡片形式嵌套显示

## 💾 数据持久化

### 本地存储（LocalStorage）
- **点赞记录**：`likedMessages`
  - 存储已点赞留言的 ID 列表
  - 刷新页面后点赞状态保持

- **最后提交时间**：`lastSubmitTime`
  - 存储上次提交留言的时间戳
  - 用于实现1分钟速率限制
  - 刷新页面后限制继续生效

### 数据库存储（PostgreSQL）
所有留言数据存储在 `messages` 表中：
- 用户名、邮箱、内容
- 父留言ID（用于回复功能）
- IP地址、User-Agent
- 点赞数、置顶状态
- 审核状态
- 创建和更新时间

## 🔧 技术细节

### 速率限制实现
```typescript
// 记录提交时间
lastSubmitTime.value = Date.now();
localStorage.setItem('lastSubmitTime', lastSubmitTime.value.toString());

// 计算剩余时间
const elapsed = Date.now() - lastSubmitTime.value;
const remaining = Math.max(0, 60 - Math.floor(elapsed / 1000));
remainingTime.value = remaining;
```

### 点赞持久化
```typescript
// 保存点赞
likedMessages.value.add(messageId);
localStorage.setItem('likedMessages', JSON.stringify([...likedMessages.value]));

// 加载点赞
const savedLikes = localStorage.getItem('likedMessages');
if (savedLikes) {
  likedMessages.value = new Set(JSON.parse(savedLikes));
}
```

### 云朵随机位置
```typescript
// 基于留言ID生成伪随机位置
const seed = message.id;
const randomX = (seed * 13 % 100);
const randomDelay = (seed * 7 % 10);
const randomDuration = 20 + (seed * 11 % 20);
```

## 🐛 常见问题

### Q1: 为什么我的留言没有显示？
**A**: 留言需要审核通过才会显示。默认状态为 `approved`，如果修改了后端代码设置为 `pending`，需要管理员审核。

### Q2: 点赞后刷新页面，点赞状态消失了？
**A**: 点赞状态保存在本地 localStorage 中，不会消失。如果清除了浏览器数据，点赞状态会重置。

### Q3: 为什么不能连续发送留言？
**A**: 为了防止刷屏，设置了1分钟的速率限制。等待60秒后可以再次发送。

### Q4: 云朵位置为什么是固定的？
**A**: 云朵位置基于留言ID伪随机生成，每次刷新位置相同，但会有浮动动画效果。

### Q5: 如何让留言显示在最上方？
**A**: 留言按创建时间倒序排列，新留言会出现在前面。如需置顶，使用管理员接口。

## 🚀 性能优化建议

1. **图片懒加载**：如果添加图片功能，使用懒加载

3. **节流防抖**：滚动事件添加节流
4. **缓存策略**：使用 Vue 的 keep-alive 缓存组件
